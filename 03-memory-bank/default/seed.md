# Example Project Memory Bank

## Bank ID
`example-project`

## Purpose
`project_knowledge`

## Mission
Store reviewed, reusable knowledge for one project.

## Scope
- Project architecture and design decisions
- Operational procedures and reproducible troubleshooting
- Verified implementation constraints and test evidence

## Recording rules
- Separate verified facts from hypotheses.
- Include source, version, date, and validation evidence where applicable.
- Do not store credentials, personal identifiers, private host details, or unrelated user history.
- Review and update stale entries rather than accumulating duplicates.
